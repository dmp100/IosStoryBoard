## ⭐ **Main Features**
- **감사 일기 작성**: 하루에 감사한 일 3가지를 기록
- **GPT 기반 AI 채팅**: OpenAI GPT API를 활용한 캐릭터와 대화
- **Supabase 실시간 동기화**: 실시간 데이터 저장 및 동기화
- **일기 목록**: 작성한 일기 모아보기
- **사용자 인증**: Supabase Auth 기반 로그인/회원가입

<br/>

## 🔐 **Backend Integration**
- **Supabase Database**: 실시간 데이터 저장 및 동기화
- **Supabase Auth**: 사용자 인증 및 세션 관리
- **OpenAI GPT API**: AI 채팅 기능 구현
- **Supabase Realtime**: 실시간 데이터 업데이트
